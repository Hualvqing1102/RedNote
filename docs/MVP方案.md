# RedNote 学习笔记 Agent · 产品 / 设计方案（v2 · 现状版）

> 本文是产品与交互设计基线，与 `docs/技术方案.md`（实现基线）配套。
> 历史高保真原型见 `docs/prototype/demo.html`；逐日开发过程见 `docs/开发记录.md`。

## 1. 定位

本地优先的个人学习助手：

- **导入**：粘贴网页链接，或直接把本地论文 PDF / DOCX / TXT / Markdown 拖进来；
- **提炼**：Agent（本地规则或云端模型）自动生成摘要、要点，可选「详细讲解模式」逐段讲透；
- **沉淀**：保存为 Markdown 笔记到本地 SQLite，可搜索、可标注、可追问；
- **规划**：内置日历（日程 / 待办 / 每周重复），把学习安排与笔记联动；
- **桌面化**：可打包为 Windows 桌面应用（文件夹版/单文件 exe），双击即用、默认离线。

## 2. 用户主流程

```
网页链接 ──┐
           ├─► 读入原文 ─► AI 提炼(摘要+要点 / 详细讲解) ─► 预览确认 ─► 存为笔记
本地文档 ──┘                                                     │
                                  ▲                              ▼
                               追问/注释                     笔记库（收藏夹分组）
                                  │                       全文搜索(FTS5) · 导出/备份
                                  └──────────────────────────┘
日历：日程 / 待办 / 每周重复 ── 点击时间即建，AI 后可一句话排入
```

## 3. 功能清单（现状）

**导入（采集页）**
- 网页采集：URL → 抓取正文、去广告导航、格式还原（标题/列表/表格/代码/粗斜体）、自动补漏与去噪；
- 本地文档导入：拖拽或选择 PDF / DOCX / TXT / Markdown；
  - 文字版 PDF / DOCX 直接提取文字；扫描版（无文字层）自动 OCR（中英文）；
  - 提取乱码时自动转 OCR，预览区可「OCR 重新识别」；桌面版可一键「打开本地文件」。

**提炼（Agent）**
- 摘要 + 要点；「详细讲解模式」用 AI 逐段详解并以此替代原文保存；
- 单篇追问（基于笔记内容回答）。

**沉淀（笔记库）**
- 按收藏夹分组浏览/管理；Markdown 正文；要点、来源展示；
- 段落级内联注释（右键任意段落，卡片可编辑、关联链接、排序）；
- 全文检索：FTS5 trigram，标题/摘要/正文加权排序（短词自动回退模糊匹配）。

**阅读体验**
- 目录大纲跳转（正文左侧独立栏）、字号 A-/A+ 调节、格式友好排版（图书馆绿 + 索引卡视觉）。

**规划（日历）**
- 月视图 / 周视图；日程(schedule)与待办(todo)；多色事件；
- 周视图：左侧统一时间刻度、点击时间栏即新建（结束自动 +1 小时）；
- 每周重复：设为「每周待办」后跨周不消失；重叠事件竖排错开。

**模型（可插拔 Provider）**
- 本地规则（Mock，默认离线）/ Claude / OpenAI 兼容端点（Ollama、LM Studio 等）；
- 国内开箱即用：**DeepSeek**、**通义千问 Qwen**（预填官方地址与模型名，只需 API Key）；
- 设置页「测试连接」一键验证 Key；隐私提示（正文是否上云）与引擎标签。

**桌面与数据**
- 桌面应用（pywebview 壳）：后端托管前端、SPA 回退，双击启动、原生文件对话框；
- 数据目录 `%APPDATA%\RedNote`（数据库 + 设置），支持环境变量重定向；
- 防锁定：单篇/全部 Markdown 导出 + SQLite 整库备份下载。

## 4. 不在本期（后续可选）

- 视频转写（ASR）/ 字幕
- RAG 向量检索 / 浏览器插件一键收藏
- 全局助手对话（B：文件夹上下文问答 + 一句话建笔记/排日历）——方案已论证，待启动
- Agent 动作扩展（润色/翻译/改写等）——入口见维护指南

## 5. 关键决策与风险

- **本地优先**：数据只存本机（SQLite 单文件），Key 只存本地，设置页不显示明文；
- **隐私提示**：正文发送云端前在 UI 明示；接本地模型可完全离线；
- **可插拔 Agent**：业务只依赖统一 Provider 接口，加模型不改业务代码；
- **离线兜底**：未配置 Key 时用本地规则 Mock，全流程可用，绝不静默冒充 AI 输出；
- **防锁定**：导出 Markdown / 备份 .db，数据始终归用户；
- **体积权衡**：内置 OCR 使桌面版约 140MB（onnxruntime + opencv + 模型）；如后续嫌大可做轻量版。
