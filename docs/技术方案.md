# RedNote 技术方案（v2 · Python + React）

> 依据 `docs/MVP方案.md` 与 `demo.html` 高保真原型产出。技术栈已定：**Python 后台 + React 工程化前端**。本方案同时服务于"界面可逐步丰富"的产品目标与"接触工程化实践"的个人目标。

## 1. 目标与范围

- **M1**：项目骨架 + 网页采集 + SQLite 本地存储 + 笔记库（搜索 / 标签 / 删除）
- **M2**：Agent 总结与追问（可插拔 Provider，默认 Claude，可接本地 DeepSeek / Ollama）
- **M3**：全文检索打磨、体验对齐 Demo、打包为桌面应用
- **不在本期**：视频转写 ASR、RAG、OCR、浏览器插件（产品方案 Phase 2）

## 2. 技术选型

| 层 | 选型 | 说明 |
|---|---|---|
| 后台 | Python 3.12 + FastAPI + Uvicorn | 开本地服务，向前端提供 REST API |
| 数据库 | SQLite（`sqlite3` / SQLAlchemy Core）+ FTS5 | 单文件、好备份；正文存 Markdown |
| 前端 | React 18 + TypeScript + Vite | 工程化主流方案，利于功能扩展 |
| 前端状态 | Zustand + 视图状态机 | 沿用「采集/笔记库/详情」三视图 |
| 样式 | 手写 CSS（CSS 变量 token） | 沿用已确认的视觉语言（图书馆绿 + 索引卡） |
| 网页采集 | `httpx` + `trafilatura` | 抓取 + 正文抽取，Python 生态最优 |
| AI 接入 | 统一 Provider 接口 | Claude + OpenAI 兼容端点（本地模型） |
| 桌面壳 | pywebview | 把界面装进桌面窗口；生产期再引入 |
| 测试 | pytest（后台）+ Vitest / RTL（前端） | 呼应 AGENTS.md「交付前测试全通过」 |
| 打包 | PyInstaller / pywebview 打包（M3） | 前期命令行启动，后期出 exe |

## 3. 总体架构

```
┌────────────────────────────────────────────┐
│   React 前端（渲染进程 / 浏览器）             │
│   采集页 · 笔记库 · 详情/追问 · 编辑          │
│   Zustand store · api client                │
└───────────────────┬────────────────────────┘
                    │ HTTP (fetch)  →   /api/*（开发期 Vite 代理到后端）
┌───────────────────▼────────────────────────┐
│        Python 后台（FastAPI 本地服务）        │
│  ┌──────────┐ ┌──────────┐ ┌────────────┐  │
│  │ 采集服务  │ │ Agent服务 │ │ 笔记服务    │  │
│  │httpx+     │ │ Provider │ │ CRUD/搜索  │  │
│  │trafilatura│ │ Claude/  │ │ (FTS5)    │  │
│  │          │ │本地兼容   │ │            │  │
│  └────┬─────┘ └────┬─────┘ └─────┬──────┘  │
│       │  httpx     │  httpx     │ sqlite3   │
└───────┼────────────┼────────────┼──────────┘
        ▼            ▼            ▼
    目标网页     Claude/本地模型   本地 SQLite
```

- **前后端分离**：前端只发请求、渲染；后端负责抓取 / 存储 / AI / 业务逻辑。
- **接口风格**：REST，`/api/*`。开发期前端由 Vite 起，代理到后端；生产期后端直接托管前端构建产物。
- **桌面化（M3）**：pywebview 打开本地服务地址，形成桌面窗口；数据与逻辑不变。

## 4. 数据模型（SQLite）

```sql
CREATE TABLE notes (
  id              INTEGER PRIMARY KEY AUTOINCREMENT,
  title           TEXT NOT NULL,
  summary         TEXT NOT NULL DEFAULT '',
  content         TEXT NOT NULL,                 -- Markdown 正文
  points          TEXT NOT NULL DEFAULT '[]',    -- 要点 JSON（M1 简单处理）
  source_url      TEXT NOT NULL DEFAULT '',      -- 原文链接
  source_snapshot TEXT NOT NULL DEFAULT '',      -- 原文概要/快照
  created_at      INTEGER NOT NULL,
  updated_at      INTEGER NOT NULL
);

CREATE TABLE tags (
  id   INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL UNIQUE
);

CREATE TABLE note_tags (
  note_id INTEGER NOT NULL REFERENCES notes(id) ON DELETE CASCADE,
  tag_id  INTEGER NOT NULL REFERENCES tags(id)  ON DELETE CASCADE,
  PRIMARY KEY (note_id, tag_id)
);

CREATE VIRTUAL TABLE notes_fts USING fts5(
  title, summary, content,
  content='notes', content_rowid='id'
);
```

## 5. 后端模块

- `app/server.py`：FastAPI 应用与路由（/api/notes、/api/collect、/api/agent、/api/settings、导出等）。
- `app/db.py`：连接管理、建表、迁移占位。
- `app/settings.py`：本地设置存储（data/settings.json，原子写入）；Key 只存本地，公开视图不回显明文。
- `app/services/notes.py`：笔记 CRUD、标签、搜索（当前 LIKE，FTS5 留待 M3 打磨）。
- `app/services/collect.py`：httpx 抓取 + trafilatura 正文抽取（Markdown，保留标题/段落/列表/表格/粗斜体）；对正文内插图注入哨兵 → 下载入库并尽量插回原位置，被抽取器丢弃的图集中到文末「原文插图」。
- `app/services/media.py`：插图以 BLOB 存 SQLite（本地优先、随库备份）；正文以 `![alt](/media/{token})` 引用；建笔记时绑定归属，删除笔记级联清理。
- `app/services/providers.py`：Provider 抽象与实现 + `build_provider(cfg)` 工厂。
- `app/services/agent.py`：摘要 / 追问编排；真实模型失败抛 AgentError（502），不静默降级。
- `app/services/export.py`：导出 Markdown（本地图片自动替换为 base64 data URI，导出文件独立可看）/ SQLite 备份。

```python
class LLMProvider(Protocol):
    async def complete(self, system: str, prompt: str) -> str: ...
```

- `MockProvider`：本地规则，默认 / 未填 Key 时使用，保证无网也能跑通全流程。
- `ClaudeProvider`：Anthropic Messages API。
- `OpenAICompatibleProvider`：任意 OpenAI 兼容端点（base_url + model + api_key），覆盖 DeepSeek 云、Ollama、LM Studio、本地部署模型。
- `build_provider(settings)`：按 `settings.json`（存于用户数据目录）实例化；选了真实 Provider 但没填 Key 时回退 Mock。

## 7. REST API

| 方法 | 路径 | 作用 |
|---|---|---|
| POST | /api/collect | body {url} → {title, content, source_url} |
| POST | /api/agent/summarize | body {title, content} → {summary, points, tags}（按当前设置选 Provider） |
| POST | /api/agent/ask | body {note_id, question} → {answer} |
| GET | /api/notes | 列表，支持 ?q= &tag= |
| POST | /api/notes | 新建笔记 |
| GET | /api/notes/{id} | 详情 |
| PATCH | /api/notes/{id} | 更新 |
| DELETE | /api/notes/{id} | 删除（连带标签关系） |
| GET | /api/tags | 全部标签 |
| GET/PUT | /api/settings | 读写模型配置（Key 不回显；返回当前生效状态） |
| GET | /api/export/notes.md | 全部笔记导出为 Markdown |
| GET | /api/notes/{id}/export.md | 单篇导出 Markdown |
| GET | /api/export/backup.db | 下载 SQLite 整库备份（含插图 BLOB） |
| GET | /media/{token} | 读取笔记插图（由正文 Markdown 引用） |

## 11. 风险与决策

- **需安装 Node.js**：React 工具链必需（前端构建 / 测试）。安装一次即可。
- **pywebview 桌面壳在 M3 引入**：前期在浏览器里开发调试，更快。
- **静态网页限制**：M1 仅支持静态 HTML；动态页后续处理。
- **隐私**：正文发云端前 UI 明示；接本地模型后可完全离线。
- **Key 安全**：本地 settings.json，不进 Git，提供清除入口。
