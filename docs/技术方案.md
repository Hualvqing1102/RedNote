# RedNote 技术方案（v3 · 现状版）

> 依据 `docs/MVP方案.md`（产品/设计）与 `docs/prototype/demo.html`（历史原型）落地。
> 本文为**实现基线**，描述当前代码的真实结构与约定；结构/维护/扩展指南另见 `docs/桌面打包与维护指南.md`，
> 逐日开发过程见 `docs/开发记录.md`。
> 技术栈：**Python 3.12 + FastAPI 后台 + React + TypeScript 前端 + SQLite(FTS5) + pywebview 桌面壳**。

## 1. 目标与状态

- **M1** ✅ 骨架 + 网页采集 + 本地存储 + 笔记库（收藏夹替代标签）
- **M2** ✅ Agent（摘要/讲解/追问，可插拔 Provider）+ 设置 + 导出备份 + 阅读体验 + 内联注释
- **M3** ✅ FTS5 全文检索 + 桌面化打包（pywebview + PyInstaller，默认文件夹版）
- **M3+** ✅ 日历（日程/待办/每周重复）、国内模型（DeepSeek/Qwen）、本地文档导入 + OCR、安全加固
- **不在本期**：ASR、RAG、浏览器插件、全局助手对话（B，待启动）

> 基线：后端 pytest **92** 通过；前端 Vitest **79** 通过；`npm run typecheck` / `vite build` 通过（AGENTS.md：交付前全绿）。

## 2. 技术选型

| 层 | 选型 | 说明 |
|---|---|---|
| 后台 | Python 3.12 + FastAPI + Uvicorn | 127.0.0.1 本地服务；桌面由 run_desktop 起线程 |
| 数据库 | SQLite（`sqlite3`）+ **FTS5(trigram)** | 单文件；正文 Markdown；`notes_fts` 外部内容表 + 触发器 |
| 网页采集 | `httpx` + `trafilatura` + `lxml` | 正文抽取、CSS-lite 样式感知标题、补漏/去噪 |
| 文档解析 | `pymupdf`(PDF) + `python-docx`(DOCX) | 上传解析 / 桌面路径读取共用同一 `fileparse` 服务 |
| OCR | `rapidocr-onnxruntime`（中英文） | PDF 文字层缺失或乱码时自动兜底；可手动「OCR 重新识别」 |
| AI 接入 | 统一 `LLMProvider` 接口 | mock / claude / openai(通用兼容) / **deepseek** / **qwen** |
| 前端 | React 18 + TypeScript + Vite + Zustand | views 目录内；无第三方 markdown 依赖，自写渲染器 |
| 桌面壳 | pywebview（Windows EdgeChromium/pythonnet） | 文件夹版打包为主，保留单文件开关 |
| 打包 | PyInstaller | `build_exe.ps1`：默认 `--onedir`，`-SingleFile` 可选 |
| 测试 | pytest + Vitest / React Testing Library | 交付门槛：全绿 + 手动走查 |

## 3. 总体架构

```
┌───────────────────────────────────────────────┐
│ 桌面壳 pywebview（或浏览器）                    │
│  React 前端：采集 / 笔记库 / 详情 / 日历 / 设置  │
│  api/client.ts（唯一 HTTP 封装）               │
│  window.pywebview.api（桌面本地能力桥，可选）    │
└───────────────────┬───────────────────────────┘
                    │ 同源 HTTP  →  /api/*（开发期 Vite 代理 :5173→:8000）
┌───────────────────▼───────────────────────────┐
│ FastAPI 本地服务（127.0.0.1）                   │
│  采集 URL │ 文档解析+OCR │ Agent │ 笔记/FTS5    │
│  收藏夹   │ 日历(事件)   │ 设置 │ 导出/备份      │
│  前端静态托管(SPA 回退)                        │
└───────────┬──────────────┬──────────────┬─────┘
            ▼              ▼              ▼
         目标网页/模型API   本地SQLite     模型(可选云端: DeepSeek/Qwen/Claude…)
```

- **前后端分离但同源托管**：开发期 Vite 代理 `/api`；生产/桌面由后端直接服务 `frontend/dist`（`/assets` 静态 + `/{path}` SPA 回退，带路径穿越防护）。
- **桌面桥（仅桌面版）**：`run_desktop.py` 注入 `js_api`（原生文件对话框、`os.startfile` 打开本地文件），并设环境变量 `REDNOTE_DESKTOP=1` 才会开放 `/api/collect/filepath`（读取本机路径解析文档）；浏览器环境无此能力。
- **离线兜底**：未配置 Key → `MockProvider` 本地规则，全流程可用；配置真实模型但调用失败 → 显式报错（502），**绝不静默用本地规则冒充 AI 输出**。

## 4. 数据模型（SQLite · `app/db.py`）

```sql
-- 笔记正文为 Markdown；时间戳为秒(本地)
CREATE TABLE folders (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL UNIQUE,
  created_at INTEGER NOT NULL
);
CREATE TABLE notes (
  id, title, summary, content, points JSON, comments JSON,
  source_url, source_snapshot, folder_id REFERENCES folders ON DELETE SET NULL,
  created_at, updated_at
);
-- FTS5 外部内容表 + trigram(中文友好)；增删改由触发器 notes_fts_ai/ad/au 同步
CREATE VIRTUAL TABLE notes_fts USING fts5(
  title, summary, content,
  tokenize='trigram', content='notes', content_rowid='id'
);
-- 日历：schedule/todo；recur='none'|'weekly'（每周重复）
CREATE TABLE events (
  id, title, kind, color, recur, start_ts, end_ts,
  all_day, done, note_id REFERENCES notes ON DELETE SET NULL,
  created_at, updated_at
);
```

- **迁移范式**：`init_db()` 全幂等——`CREATE TABLE IF NOT EXISTS` + 按列名 `ALTER TABLE ADD COLUMN` + 触发器 `IF NOT EXISTS`；老库启动自动升级（含 FTS 首次回填 `rebuild`）。历史遗留 media/tags/note_tags 表在建表时彻底移除。
- 注释卡片结构：`[{id, text, links:[{title,url}], anchor?}]`，anchor 为段落序号。

## 5. 后端模块

| 文件 | 职责 |
|---|---|
| `app/server.py` | 全部 `/api/*` 路由、上传(FormData)、静态托管、桌面路径接口守卫 |
| `app/db.py` | 连接、SCHEMA、幂等迁移、FTS5 建表/触发器/回填、`fts_available()` |
| `app/settings.py` | Provider 注册表(deepseek/qwen/claude/openai/mock)、默认值、校验、公开视图脱敏、原子写 |
| `app/services/collect.py` | 网页抓取、正文抽取、CSS-lite 样式感知标题、补漏/去噪 |
| `app/services/fileparse.py` | PDF/DOCX/TXT/MD 解析；PDF 乱码/无文字层自动转 OCR；`SUPPORTED_EXTS` |
| `app/services/agent.py` | summarize / explain / ask；SYSTEM_* 提示词；`AgentError` |
| `app/services/providers.py` | Mock / Claude / OpenAI 兼容(openai/deepseek/qwen) 工厂；`test_connection()` |
| `app/services/notes.py` | 笔记 CRUD、注释规整、`_fts_search`（bm25 加权 10/2/1，短词回退 LIKE） |
| `app/services/folders.py` / `export.py` | 收藏夹；Markdown/SQLite 导出 |
| `app/services/events.py` | 事件 CRUD + `_expand_weekly` 每周重复按区间展开 |
| `run_desktop.py` | 桌面入口：起服务→等待就绪→pywebview 窗口；`DesktopApi`(选文件/打开文件) |

**Provider 工厂规则**：`provider=mock` 或选了真实 Provider 但未填 Key → Mock；openai/deepseek/qwen 走 `OpenAICompatibleProvider(base_url, model, api_key)`（POST `{base_url}/chat/completions`）；claude 走 Anthropic Messages。模型 Key 只存 `data/settings.json`（或 `%APPDATA%\RedNote`），公开视图永不回显明文。

## 6. 前端结构

```
frontend/src/
  main.tsx / App.tsx           # 壳与路由级视图切换
  api/client.ts                # 唯一 HTTP 封装(含 FormData/FormData 不设 JSON 头)
  types.ts                     # 前后端共享类型(含 EventItem/recur/ProviderName)
  lib/markdown.tsx             # 自写 Markdown 渲染器(scheme 白名单防 XSS)
  lib/provider.ts              # 引擎描述 / 是否上云 / 标签
  lib/annotations.ts           # 注释定位工具
  store/useAppStore.ts         # Zustand
  views/CollectView.tsx        # 采集：URL + 拖拽文档 + 提炼/讲解 + OCR/打开本地
  views/LibraryView.tsx        # 笔记库：搜索框 + 收藏夹筛选
  views/NoteView.tsx           # 详情：正文/目录/追问/内联注释
  views/CalendarView.tsx       # 日历：月/周、抽屉编辑、每周重复、泳道/竖排
  views/SettingsView.tsx       # Provider 配置 + 测试连接 + 备份导出
  styles/global.css
```

安全要点：Markdown 全部经 React 默认转义渲染；链接/图片按 scheme 白名单（http(s)/mailto/站内路径）渲染，拦截 `javascript:` 等危险协议；无 `dangerouslySetInnerHTML`。

## 7. REST API（实际）

| 方法 | 路径 | 作用 |
|---|---|---|
| POST | /api/collect | {url} → {title, content, source_url}（网页采集） |
| POST | /api/collect/file | multipart(file, force_ocr?) → 解析本地文档(含 OCR) |
| POST | /api/collect/filepath | {path, force_ocr} 桌面专用读取本机路径 |
| POST | /api/agent/summarize | {title, content} → {title, summary, points}（无 tags） |
| POST | /api/agent/explain | → {title, explanation}（详细讲解） |
| POST | /api/agent/ask | {note_id, question} → {answer} |
| GET/POST/PATCH/DELETE | /api/notes[/id] | 笔记 CRUD（?q= FTS、&folder=） |
| GET/POST/PATCH/DELETE | /api/folders[/id] | 收藏夹管理 |
| GET/POST/PATCH/DELETE | /api/events[/id] | 日历事件 CRUD（GET 支持 start/end 区间+每周展开） |
| GET/PUT | /api/settings | 模型配置读写（脱敏视图 + 生效状态） |
| POST | /api/settings/test | 用当前(或已存)配置发极小请求验证连通性 |
| GET | /api/export/notes.md、/api/notes/{id}/export.md、/api/export/backup.db | 导出/备份 |

## 9. 运行与打包

```bash
# 开发：后端（终端1）→ 前端（终端2）
.venv\Scripts\python -m uvicorn app.server:app --reload --port 8000
cd frontend && npm run dev        # http://localhost:5173

# 桌面文件夹版（默认）/ 单文件版
powershell -ExecutionPolicy Bypass -File build_exe.ps1
powershell -ExecutionPolicy Bypass -File build_exe.ps1 -SingleFile
# 前置：cd frontend && npm run build；并退出正在运行的 RedNote
```

数据目录：`REDNOTE_DATA_DIR` 未设置时默认 `data/`（源码）/ `%APPDATA%\RedNote`（exe）。备份 = 复制整个目录或使用设置页导出。

## 10. 风险与决策（历史与现状）

- **Electron → pywebview 回退**：Demo 阶段曾考虑 Electron，后回退为 Python+React(v2)；桌面壳最终用 pywebview（体积小、与 Python 后台同栈），PyInstaller 默认文件夹版（打包/启动快），单文件保留开关。
- **中文搜索**：SQLite LIKE 无分词 → FTS5 **trigram**（对 <3 字短词自动回退 LIKE）。
- **乱码 PDF**：字体缺 ToUnicode 映射时提取为乱码 → 字符质量启发式自动转 OCR；扫描件无文字层 → 自动 OCR；仍可手动「OCR 重新识别」。
- **OCR 体积**：内置中英文 OCR 使 exe ≈140MB；接受此代价换取扫描件可用。
- **图片抓取**：曾实现后**下架**（f1909c7），专注文本格式；media 表迁移时清理。
- **隐私与安全**：Key 本地明文存储（仅本机）；接口不回显；服务绑 127.0.0.1 + CORS 白名单；Markdown scheme 白名单防 XSS；桌面 `/api/collect/filepath` 仅在桌面环境开放。
- **时间戳**：日历存秒(本地)；重复事件按星期几 + 锚点日期展开，早于锚点不出现。
